# EWF 加载、浏览与复核实测

2026-11-19，Windows，项目虚拟环境，随项目分发的 TSK 4.15.0。测试只读使用本地样本，不附带证据、文件清单或导出副本。以下为本机观测值，不是吞吐量保证。

| 操作 | 范围和结果 | 用时 |
| --- | --- | ---: |
| 首次载入 | 15 个分段，共 16,065,168,064 字节；解码 50 GiB、固定逻辑和分段 SHA-256、识别分区并检查卷声明 | 184.36 秒 |
| 全分区扫描 | 扫描前后均重算 15 段摘要；3 个 NTFS 分区分别得到 322、532,039、70 项，合计 532,431 项；含写入清单 | 102.20 秒 |
| 重开已保存的案件 | 读取并解压 12,189,616 字节的清单，不再扫描镜像 | 1.85 秒 |
| 准备文件树 | 在后台按分区、父目录建索引；与读取清单合计约 2.93 秒 | 1.08 秒 |
| 显示首页 | 已准备好索引后，Qt 离屏实例创建首页并处理事件，不含重开和建索引 | 0.027 秒 |
| 展开大目录 | 实际选择含 91,798 项的目录；左侧显示 359 组，右侧显示前 100 行，并验证末项可定位 | 0.056 秒 |
| 指定文件 HEX 搜索 | 可执行文件内找到 7 处匹配，含偏移 0 的 MZ；含两次完整分段校验 | 26.03 秒 |

原先每次选择目录都遍历整案。用同一批记录复跑原筛选表达式，3 次取中位数，单是筛选该大目录就需 0.326 秒；索引查找得到相同记录，后续界面开销见表。这里没有把微秒级的字典查找时间当作实际点击时间。

完整逻辑流的 SHA-256 与 Guymager 采集记录中的交付摘要一致；另一次独立调用 img_cat 并计算 SHA-256 也得出相同结果。三个卷的声明范围均在逻辑介质内。另一份 4 GiB NTFS 样本则提示声明范围超出镜像。两种结论均不代表对原物理介质的独立采集验证。

对搜索命中记录取证笔记、导出对应文件并复核起始字节；生成复核包后，用独立核验脚本校验外部 ZIP 摘要、8 份包内材料及审计链。大镜像未进行不限定文件的全文穷举性能测试。首轮摘要与底层基准有部分并发，缓存和机器负载影响耗时，不据此计算加速比。
