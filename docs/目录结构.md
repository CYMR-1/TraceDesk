# 目录结构与维护指南

## 总体结构

根目录保留启动入口与依赖配置。源码按案件业务、底层引擎、功能模块和界面分组；演示输入、案件输出、第三方工具和本地生成文件各有独立位置。

## 增删功能

桌面版默认启用全部十个功能模块（见 `forensic/features/config.py`）。`cases`、`evidence`、`files` 组成基础工作流；`export`、`file_tools`、`report`、`timeline`、`audit`、`help`、`review` 可分别启停。

- **停用**　在 `forensic/features/config.py` 的 `ENABLED_FEATURES` 中移除可选功能标识并重启。对应按钮、标签和刷新回调一起停用。重新加入标识即可恢复。例如移除 `audit` 会关闭日志查看页，案件操作仍照常记录审计日志。
- **新增**　在 `forensic/features/` 新建模块，导出一个 `FEATURE`。在 `catalog.py` 的 `MODULES` 中登记模块路径，并在启用清单中加入标识。下面是可直接登记的只读页面示例。
- **删除**　移除启用项、模块映射和对应模块文件，检查其他模块的 `requires`。案件数据格式与历史输出由 `core/` 管理。
- **操作按钮**　通过 `Action` 声明按钮名称、处理函数和位置。位置可选 `brand`、`header`、`evidence`、`preview`、`file_menu`。预览区与右键菜单操作可用 `accepts_entry` 指定哪些文件记录可操作。耗时操作调用 `context.task`，由工作台统一管理忙碌状态。

```python
from .api import Feature, Panel

def render_count(context):
    case = context.case()
    if case is None:
        return '请先打开案件'
    return f"清单共 {len(case.data['inventory'])} 项"

FEATURE = Feature('counts', requires=('files',),
                  panels=(Panel('counts', '清单统计', render_count),))
```

依赖方向为入口 → 界面控制器 → 案件业务 → 引擎适配；预览视图通过 `core/preview.py` 的读取器获取字节。业务和引擎模块不导入 Qt。共用资源路径从 `forensic.paths` 导入，不在搬动后的模块中推算 `__file__.parent.parent`。脚本入口可用自己的位置将项目根目录加入导入路径。

## 数据与生成文件

- `evidence/` 是输入。只跟踪并打包上述四个自建演示文件；用户自行加入的镜像保持在本地，不自动进入 Git 或源码包。现有镜像文件没有搬动，已记录的案件路径继续有效。
- `cases/` 是输出。每个案件独立包含 `case.json`、`audit.jsonl`、`audit.head`、`case.lock`、`exports/` 和 `reports/`（大清单案件另含 `inventory-*.jsonl.gz`）。源码包只保留 `cases/.gitkeep`。
- `logs/startup.log` 保存错误信息；`logs/latest-demo.txt` 保存最近一次演示案件位置。
- `dist/`、`.venv/`、`__pycache__/` 和运行案件不入库、不打包。整理目录不会清空已有案件、证据或本地环境。
- `tools/` 中的官方发行结构不拆分；程序运行依赖完整的 DLL，分发还需保留许可证。

## 常用命令

在项目根目录执行。使用 Python 前先创建 `.venv`，第三方依赖仅安装到该虚拟环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_gui.py -v
.\.venv\Scripts\python.exe scripts/run_demo.py --gui
.\.venv\Scripts\python.exe scripts/make_icon.py
.\.venv\Scripts\python.exe scripts/package.py
.\.venv\Scripts\python.exe scripts/verify_bundle.py "复核包路径.zip" --sha256 独立取得的64位摘要
```

新增模块放到对应职责目录，新增测试放到相应测试子包。更新目录时同步检查 Python 导入、测试补丁路径、`paths.py`、文档链接和解压后的工程包；目录清单集中更新本文，避免多处复制后失效。
