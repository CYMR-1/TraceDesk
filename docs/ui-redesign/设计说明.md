# TraceDesk UI 设计预览

状态：待用户审阅。此目录只提供设计稿，不接入取证业务，也不修改现有 PySide6 界面。

## 设计方向

- 主体采用纯白色（#FFFFFF）：主工作区、文件列表、详情面板、标题栏和底部状态栏统一白底；侧栏与辅助条使用浅灰，陶土色突出主操作与选择状态，灰绿表示校验状态。
- 左侧固定导航组织文件浏览、镜像与文件系统、MAC 时间线、审计日志和报告；新建、打开案件放在侧栏底部。
- 案件与证据镜像持续可见。页面级操作和文件级操作分开，导出所选文件靠近预览区。
- 桌面宽屏采用文件列表与右侧详情，列表突出名称、状态、大小，完整路径、inode 和时间移到详情中。正式实现时仍需保留全部元数据可访问性。
- 窄窗口改为上下布局，避免压缩文件预览；密度和详情位置可在设计预览中调整。
- 保留现有单案件、单 RAW 镜像的产品范围，保留底层结构和空间区域入口。

## 可审阅内容

`tracedesk-preview.html` 是可在对话内展示的自包含设计片段，支持导航、搜索、状态过滤、文件选择、文本/十六进制切换、新建表单及操作反馈预览。

界面数据均为示例。文件名、记录大小和镜像摘要参考项目演示清单；inode、时间、删除状态、文本内容、审计事件和校验状态用于展示布局，不代表实际取证结果。预览不读取镜像、不创建案件、不执行导出或生成真实报告。
