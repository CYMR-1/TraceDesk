# TraceDesk 浅色多彩界面

更新于 2026-11-18。用户要求在线寻找鲜亮的 UI 方案并借鉴，随后明确“配色可以多一些”。本次在既有白色、浅灰主体上加入功能强调色，不使用陶土色，也不改为蓝白主题。

## 在线参考

| 官方来源 | 借鉴内容 | TraceDesk 的处理 |
| --- | --- | --- |
| [Files](https://files.community/) | 现代 Windows 文件管理器、文件类型与颜色辅助识别 | 白色文件树与内容面板、细边框、小圆角、彩色文件图标 |
| [Fluent 2：颜色](https://fluent2.microsoft.design/color) | 中性色承载内容，品牌色用于关键操作和选中态；状态色配合其他信息 | 翠绿主操作、薄荷色选中行、紫色辅助操作，删除状态保留文字并使用玫红 |
| [Fluent 2：树](https://fluent2.microsoft.design/components/web/react/core/tree/usage) | 分层缩进、可展开节点、容易识别的前置图标 | 保留镜像 → 分区 → 根目录 → 文件的完整层级，图标区分磁盘、目录及文件类型 |
| [Carbon：数据表格](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) | 搜索筛选工具栏、明确表头、可选交替行底色 | 筛选栏紧邻结果列表，弱化纵向网格，以浅灰表头和轻微交替行底色辅助阅读 |

借鉴的是视觉组织和组件使用方式。图标由项目的 Qt 绘图代码绘制，未引入网页脚本、第三方图标包或远程运行依赖。

## 颜色职责

| 用途 | 颜色 |
| --- | --- |
| 主要内容面板 | 白色 `#FFFFFF` |
| 工作台背景 | 浅灰 `#F5F6F8` |
| 主要文字 | 深灰绿 `#24332F` |
| 加载镜像、主要操作 | 翠绿 `#087F6B` |
| 选中行 | 薄荷底色 `#DFF3EB`，深绿文字 |
| 报告、磁盘图标、系统区域状态 | 紫色，配浅紫底色 |
| 文件夹 | 金色描边与浅金填充 |
| 图片文件 | 玫红图标 |
| 表格文件 | 草绿色图标 |
| 删除状态 | 玫红 `#B64262`，同时保留“已删除”等明确文字 |

图标颜色只表示类型，绿色操作按钮不代表证据校验成功。校验结果继续由实际任务与日志给出。

## 保持的交互

- 加载镜像后自动展示所有分区；完整文件树保留删除记录、虚拟目录及系统区域。
- 主导航与加载、校验按钮共享等高行；编码选择与文本/十六进制标签对齐，无原生标签页多余基线。
- 预览占满右下区域，编码在右上，分页在右下；不恢复元数据侧栏或“状态详情”弹窗。
- 搜索只改变结果列表，树与列表继续双向定位；窄窗口在数据区内滚动，分隔条仍可拖动。

主题位于 `forensic/ui/appearance.py`，彩色图标与文件类型映射位于 `forensic/ui/icons.py`。旧 HTML 及已发布的 Sites 页面保留历史设计；当前效果以桌面截图和源码为准。
