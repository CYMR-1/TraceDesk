# TraceDesk UI 设计预览

状态：设计已确认并落实到 PySide6 正式界面。本文保留设计预览说明；真实窗口与实现验证见 [实施与验证](实施与验证.md)。HTML 预览仍只使用示例数据。

## 设计方向

- 整体仅使用白色与灰阶：主工作区、文件列表、详情面板、标题栏和底部状态栏采用纯白色（#FFFFFF）；侧栏、按钮、选中行与辅助条使用浅灰，文字与图标采用深灰保证可读性。状态通过文字标签区分，不再使用陶土色、绿色等彩色强调。配色固定，不恢复旧预览保存的强调色。
- 参考 Autopsy 的 Tree Viewer / Result Viewer / Content Viewer 分区方式：左侧为完整文件树，右上为文件列表，右下为内容与元数据。模块导航与新建、打开案件移至顶部，为目录树留出空间。
- 案件与证据镜像持续可见。页面级操作和文件级操作分开，导出所选文件靠近预览区。
- 文件树展示镜像、分区、根目录、所有目录和文件（含已删除条目），默认展开；支持逐级展开折叠、全部展开和全部折叠。树由示例路径构建，不是平铺的快捷入口。
- 点击目录更新当前目录列表；点击树中任意文件定位到其父目录并显示内容；点击列表文件会展开树中祖先节点。搜索和状态筛选只影响当前目录的结果列表，不裁剪完整文件树。
- 列表展示名称、状态、大小、inode 以及 M/A/C 时间，窄窗口仅在表格内部横向滚动；下方始终提供文件属性、完整时间和文本/十六进制预览。
- 窄窗口重排为上下布局，保留文件树可见；目录树宽度与列表密度可在设计预览中调整。
- 保留现有单案件、单 RAW 镜像的产品范围，保留底层结构和空间区域入口。

## 可审阅内容

`tracedesk-preview.html` 是可在对话内展示的自包含设计片段，支持完整树的展开折叠、目录定位、文件与内容联动、导航、搜索、状态过滤、文本/十六进制切换、新建表单及操作反馈预览。底层结构入口展示后续的字节查看流程，当前只提供操作提示。

布局参考：[Autopsy 官方 UI Layout 文档](https://www.sleuthkit.org/autopsy/docs/user-docs/4.14.0/uilayout_page.html)。仅借鉴信息分区与浏览方式，沿用本项目白灰视觉与现有功能范围。

界面数据均为示例。文件名、记录大小和镜像摘要参考项目演示清单；inode、时间、删除状态、文本内容、审计事件和校验状态用于展示布局，不代表实际取证结果。预览不读取镜像、不创建案件、不执行导出或生成真实报告。

## 正式实施

已将布局映射到 PySide6 原生控件，继续复用现有案件、TSK、后台任务和预览读取接口。正式界面用可拖动分隔条调整树宽、列表高度和元数据宽度；HTML 中的密度调整及移动端重排仅为设计探索，桌面版按实际屏幕工作区设置最小窗口尺寸。真实目录树展示本次读取分区的完整清单。

## 预览检查

已用本机 Chrome 实际渲染并检查：

- 桌面主视图及 1024、736、320 像素视口，无页面横向溢出。
- 搜索路径、空搜索结果、已删除筛选、选中文件与文本/十六进制切换。
- 树中包含全部 5 个示例文件，目录选择、文件定位、展开折叠、列表反向定位与树在筛选后保持完整。
- 镜像、时间线、审计、报告、新建案件、打开案件、操作说明与文件浏览导航。
- 浏览器未报告脚本异常。

以上为设计阶段检查；正式实现的回归与真实镜像流程另见实施记录。
